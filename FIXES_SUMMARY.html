Critical Security

Remote Code Execution Vulnerabilities

✓ RCE via Command Injection
server.py:109
Problem

Using shell=True with unsanitized input allows attackers to execute arbitrary commands on the server.

subprocess.Popen(cmd, shell=True, ...)
Solution

Removed shell=True and added command validation to block dangerous patterns.

dangerous_patterns = ['rm -rf', 'del /', 'format', ...]
if any(pattern in command.lower() for pattern in dangerous_patterns):
    return error('Dangerous pattern detected')
✓ Unvalidated Application Input
server.py:73-122
Problem

No validation on application name and arguments allows passing malicious commands.

app_name = data.get('app')  // No validation
args = data.get('args', [])  // No validation
Solution

Added regex validation for app names and blocked dangerous characters in arguments.

if not re.match(r'^[\w\-\.]+$', app_name):
    return error('Invalid application name')

dangerous_chars = ['&', '|', ';', '$', '`', ...]
for arg in args:
    if any(char in arg for char in dangerous_chars):
        return error('Dangerous characters')
✓ Overly Permissive CORS
server.py:16
Problem

CORS enabled without restrictions allows any website to communicate with the server.

CORS(app)  // Allows all origins
Solution

Restricted CORS to localhost and file:// origins only.

CORS(app, origins=[
    'http://localhost:*',
    'http://127.0.0.1:*',
    'file://*'
])

Cross-Platform & API Issues

✓ Windows Disk Path Error
server.py:57
Problem

Using Unix path / fails on Windows systems.

disk = psutil.disk_usage('/')  // Fails on Windows
Solution

Added platform detection for correct disk path.

if platform.system() == 'Windows':
    disk = psutil.disk_usage('C:\\')
else:
    disk = psutil.disk_usage('/')
✓ Invalid Fetch Timeout
actions.js:33-42
Problem

The timeout property doesn't exist in the Fetch API.

await fetch(url, { timeout: 2000 })  // Invalid
Solution

Used AbortController with setTimeout for proper timeout handling.

const controller = new AbortController()
const timeoutId = setTimeout(() => controller.abort(), 2000)
await fetch(url, { signal: controller.signal })
clearTimeout(timeoutId)
✓ Memory Leak in Event Listeners
deck-core.js:122-157
Problem

Event listeners added but never removed, causing memory leaks.

Solution

Stored handlers for cleanup and added proper removal in clear() method.

button._handlers = { mousedown, mouseup, ... }
// Later in clear():
element.removeEventListener('mousedown', btn._handlers.mousedown)
✓ Resource Cleanup on Page Unload
index.html
Problem

Live widgets and intervals continued running after page close.

Solution

Added beforeunload event handler to clean up resources.

window.addEventListener('beforeunload', () => {
    if (window.streamDeckApp.liveKeys) {
        window.streamDeckApp.liveKeys.stopAll()
    }
})
