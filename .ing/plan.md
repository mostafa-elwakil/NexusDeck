# خطة مشروع محاكي Stream Deck الافتراضي (StreamDeck Studio & Simulator)

## نظرة عامة
إنشاء مشروع جديد ومستقل بالكامل داخل مجلد منفصل باسم `streamdeck-simulator/`، يحاكي جهاز **Elgato Stream Deck** و **CYD Display** بشكل تفاعلي وواقعي جداً، دون المساس أو التعديل على ملفات المشروع القديم (`backend/`, `firmware/`, `scripts/`).

المشروع سيوفر:
1. **جهاز Stream Deck تفاعلي بالكامل (Virtual Deck)**: شاشة تحكم تفاعلية بأزرار LCD واقعية ثلاثية الأبعاد (3D tactile keys) مع تأثيرات الضغط الميكانيكي، إضاءة RGB، وأصوات نقر اختيارية.
2. **وضع المحاكي المزدوج (Dual-Mode)**:
   - **وضع العرض والتشغيل (Deck Player)**: واجهة نظيفة وسريعة يمكن فتحها على أي متصفح، كمبيوتر، أو حتى هاتف/تابلت لتحويله إلى جهاز Stream Deck فعلي يعمل باللمس.
   - **وضع الاستوديو والتخصيص (Studio Editor)**: مصمم مرئي لتعديل الأزرار، تغيير الأيقونات، الألوان، الإجراءات، وإنشاء الماكرو بالسحب والإفلات.
3. **أحجام متعددة للأجهزة (Hardware Presets)**:
   - **CYD OpsDeck** (4 × 3 = 12 زر)
   - **Stream Deck Mini** (3 × 2 = 6 أزرار)
   - **Stream Deck Classic** (5 × 3 = 15 زر)
   - **Stream Deck XL** (8 × 4 = 32 زر)
4. **محرك إجراءات ذكي (Smart Actions Engine)**:
   - **إجراءات النظام**: تشغيل برامج، فتح روابط، تنفيذ أوامر Shell / PowerShell، ونسخ نصوص.
   - **إجراءات حية (Dynamic Live Keys)**: عداد استهلاك المعالج والذاكرة (CPU/RAM gauge)، ساعة وتاريخ حي، مؤقت زمني.
   - **إجراءات DevOps وشبكات**: فحص الروابط (HTTP Health Check)، فحص السيرفرات (Ping)، أوامر دوكر ومحددات الحالة.
   - **إجراءات ماكرو متعددة الخطوات (Macros)**: تنفيذ سلسلة إجراءات متتالية بتأخير زمني.
   - **إجراءات التنقل بين الصفحات والبروفايلات**: أزرار Next / Prev والتنقل لصفحات محددة.
5. **سيرفر خفيف اختياري (Companion Server)**:
   - كود بايثون خفيف لتنفيذ أوامر الويندوز الحقيقية، مراقبة موارد الجهاز، وفتح البرامج، مع عمل الواجهة تلقائياً في المتصفح حتى بدون السيرفر عبر تخزين `LocalStorage`.

## تفاصيل المكونات والمميزات

### 1. واجهة جهاز Stream Deck الواقعية (Deck Engine)
- تصميم كبسولات الأزرار مع تأثيرات انعكاس زجاج الـ LCD (Glassmorphism & inner glow).
- دعم الحالات المتعددة للزر:
  - **Idle (خامل)**: لون مخصص مع أيقونة وعنوان.
  - **Pressed (مضغوط)**: حركة ضغط فيزيائية للداخل وتوهج لوني.
  - **Running / Loading (قيد التنفيذ)**: دائرة تحميل دوارة مع توهج أزرق.
  - **Success (نجاح)**: إضاءة خضراء مع وميض تأكيد.
  - **Error (فشل)**: إضاءة حمراء مع اهتزاز تحذيري.
- صوت نقر لمسي اختياري (Haptic sound effects) باستخدام Web Audio API (بدون ملفات صوت خارجية).

### 2. الأزرار الديناميكية الحية (Live Widgets)
- **CPU & RAM Monitor**: زر يعرض نسبة استهلاك المعالج والرام مع شريط رسم بياني ملون يتحدث تلقائياً.
- **Clock & Calendar**: زر يعرض الوقت الحالي بالثواني والتاريخ.
- **Stopwatch / Pomodoro**: زر مؤقت زمني قابل للبدء والإيقاف بنقرة واحدة.
- **System Ping**: زر يقيس زمن استجابة الإنترنت (Latency ms).

### 3. خادم الرفيق المحلي (Companion Server)
- خادم بايثون مدمج صغير جداً وسريع.
- يوفر API endpoints آمنة:
  - `/api/run-command`: لتشغيل أوامر cmd/powershell.
  - `/api/open-app`: لفتح تطبيقات (مثل VS Code، Terminal، المتصفح).
  - `/api/system-stats`: جلب استهلاك المعالج والذاكرة الحقيقي لنظام التشغيل.
  - `/api/http-proxy`: لتجاوز قيود CORS عند فحص الروابط المحلية.

## خطة التحقق والاختبار (Verification Plan)

### الاختبارات الوظيفية:
1. **تشغيل المحاكي في المتصفح**:
   - فتح `streamdeck-simulator/index.html` والتأكد من عرض هيكل الـ Stream Deck بالأزرار التفاعلية.
   - تجربة الضغط على الأزرار ورؤية استجابة الألوان والحركات.
2. **اختبار التنقل والتعديل**:
   - التبديل بين البروفايلات الجاهزة (DevOps, Media, Productivity).
   - تعديل زر (تغيير اسمه، لونه، وأيقونته) والتأكد من حفظ التعديل في `LocalStorage`.
   - التبديل بين أحجام الأجهزة (Mini 3x2, CYD 4x3, Classic 5x3, XL 8x4).
3. **اختبار الخادم المحلي (Companion Server)**:
   - تشغيل `python server/server.py` واختبار اتصال المحاكي به لجلب موارد الجهاز الحقيقية وتنفيذ أمر تجريبي.
4. **ضمان عدم المساس بالمشروع القديم**:
   - التحقق عبر `git status` أن مجلدات `backend/`, `firmware/`, `scripts/` لم يطرأ عليها أي تغيير.
