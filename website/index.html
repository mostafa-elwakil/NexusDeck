How it works

Three steps from parts to a working macro deck.

Flash the ESP32

Get the firmware from the releases page and flash it to an ESP32-2432S028R (2.8" touch) "Cheap Yellow Display".

Install the companion

Run the signed Windows installer or the Linux script. It runs a free local server that keeps everything in sync.

Open https://nexusdeck/ and drag buttons

Design your deck in the web Studio: drag buttons onto the 8×4 grid, pick actions, save — it's on the device instantly.

FAQ

Quick answers to the usual questions.

Do I need the internet?

No. NexusDeck runs entirely on your local network over HTTPS at https://nexusdeck/. Your deck config, widgets and LED matrix all talk to the companion server on your own LAN — no cloud involved. (Only the Spotify and Calendar integrations reach out to their own APIs if you enable them.)

Is it free?

Yes — NexusDeck is free and open source. No subscriptions, no accounts, no paywalled features. Star it on GitHub if it's useful to you.

Which device do I need?

The ESP32-2432S028R — the well-known 2.8" resistive-touch "Cheap Yellow Display" (CYD). It costs around $10 and is widely available. The WS2812B 8×8 LED matrix is optional (wired to GPIO22, no soldering needed on CN1).

What about the LED strip?

The WS2812B 8×8 matrix (data on GPIO22) gets WLED-style presets: rainbow, fire, comet, twinkle, confetti, marquee, gradient, chase and breathe. Pick presets and colors from buttons on the deck or the 💡 Light panel in the Studio — settings sync automatically.

Windows flags the installer — is that normal?

SmartScreen may show a "Windows protected your PC" prompt for unsigned builds. Click More info → Run anyway; the installer is built from the same public source code in this repository.
